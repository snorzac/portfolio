Android Music Mobile App

Android Studio

Built a fully functional music player app in Android Studio using Java, tested through a built-in emulator.

Developed alongside my UI/UX module, I gained hands-on experience with the full product design cycle - from wireframe to implementation.

Key features:

  • Playback controls: play, pause, next, previous, repeat, and shuffle
  • User registration, login, and delete user accounts
  • Firebase Authentication for secure login

Adobe Xd

I designed the app's interface in Adobe XD - starting with lo-fi wireframes to map user flow, then hi-fi prototypes to finalise the visual design.

To validate the design, I conducted usability testing using the System Usability Scale (SUS) survey, then used the feedback to refine the UI before coding development.
