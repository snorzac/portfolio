Built a full-stack website using HTML, CSS, JavaScript, and SQL, where users can discover restaurants and share their reviews for a school project.

I gained hands-on experience connecting both front-end and back-end interfaces together.

Main feautres include:

  • view, add, update, and delete reviews with ratings
  • register and login
  • update profile

I learned a lot about web design and the importance of visual hierarchy, colour theory, and user experience, which sparked my interest in building a clean and visually appealing web design.

Lo-fi & EER Diagram

While working on my wireframe prototype, I took design inspirations from apps and websites like FoodPanda, Golden Village, and Amazon.

The Enhanced Entity-Relationship (EER) diagram maps the main database structure between key entities like users, restaurants, and reviews.

Though the end result did not have as many features as initially planned, this project still remains my proudest work that I have done.
